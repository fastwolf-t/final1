# final1
Это проект для валидации операций клиента, написанный на языке программирования python.<br>
Проект использует poetry (популярный инструмент для управления зависимостями)

# Запуск проекта
Для проверки проекта по flake8, mypy, isort запустите файл shell/check.sh
```sh
chmod +x ./shell/check.sh
./shell/check.sh
```
Для запуска проекта запустите файл shell/run.sh (демонстрация всего функционала проекта)
```sh
chmod +x ./shell/run.sh
./shell/run.sh
```

# Тестирование проекта на ошибки
Для тестирования проекта на наличие ошибок можете сделать так:
```sh
chmod +x ./shell/test.sh
./shell/test.sh
```
Данная команды автоматически запустит тесты, которые определены в папке tests/*
